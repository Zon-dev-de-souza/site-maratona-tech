# Project Midnight

Projeto desenvolvido para a Maratona Tech 2026.

## Sobre

O Project Midnight é uma plataforma que reúne recursos educacionais gratuitos
para estudantes e apresenta uma ferramenta de proteção de prompts.

## Funcionalidades

- Recursos gratuitos de programação
- E-books gratuitos
- Materiais de Português
- Materiais de Inglês
- Matemática básica para vestibular
- Detector de informações pessoais
- Proteção de prompts
- Minimização de dados pessoais

## Protetor de Prompt

O protetor utiliza Python e expressões regulares (Regex) para
identificar informações como:

- CPF
- Telefone
- E-mail
- CEP
- Nome
- Idade
- Endereço
- Escola
- Informações financeiras
- Opiniões políticas

Após a identificação, o sistema gera uma versão mais segura
do texto, removendo ou generalizando informações desnecessárias.

## Tecnologias

- Python
- Streamlit
- Regex
- GitHub

## Objetivo

Facilitar o acesso a recursos educacionais gratuitos e incentivar
o uso consciente da tecnologia e da inteligência artificial
no ambiente educacional.
